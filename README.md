# Md Raiyaan Tarique — Portfolio

An interactive portfolio presenting my software development, AI, automation, and web projects.

**[Visit the portfolio](https://ryntrq.vercel.app)** · **[GitHub](https://github.com/RynTrq)** · **[LinkedIn](https://www.linkedin.com/in/md-raiyaan-tarique-548956313/)**

## Experience

Built with React, Vite, Tailwind CSS, Framer Motion, and Three.js. The interface combines project case studies, a scroll-driven visual scene, reusable components, and a dedicated project-media collection.

## Run locally

Use a current Node.js LTS release and npm.

```bash
git clone https://github.com/RynTrq/Portfolio.git
cd Portfolio
npm ci
npm run dev
```

Open the local address printed by Vite.

## Development commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Build the site for deployment |
| `npm run preview` | Preview the built site |
| `npm run lint` | Run the configured lint checks |
| `npm run typecheck` | Run the project's configured type checks |

## Source guide

- `src/components/portfolio/` — portfolio sections and visual interactions.
- `src/components/ui/` — reusable interface components.
- `public/project-media/` — project screenshots used in case studies.
- `src/components/AppErrorBoundary.jsx` — application error boundary.

Project descriptions and media should reflect the corresponding source repositories. A successful frontend build does not verify external project deployments.
